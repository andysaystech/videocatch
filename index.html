📱 手機版使用方法（iPhone 編輯書籤 / Android Firefox）
🍎 iPhone / iPad — 編輯書籤法
手機 Safari 沒辦法「拖」書籤，但可以先存一個書籤、再把它的網址改成下面這段程式碼，效果一樣。只要做一次。
  1. 點下方按鈕複製這段 javascript: 程式碼
  2. 在 Safari 隨便開一個網頁 → 點分享鈕 􀈂 → 「加入書籤」→ 儲存（名稱先隨意）
  3. 點 Safari 的書籤圖示 􀉜 → 右下「編輯」→ 點剛剛那個書籤
  4. 把名稱改成「抓影音」；下面那欄網址全選刪掉，貼上剛複製的程式碼 → 完成
  5. 之後在任何影片頁，點書籤 􀉜 → 點「抓影音」，就會把該頁影音帶回本站 ✅
⚠️ 第 4 步貼上後，確認網址欄是 javascript: 開頭。若貼上時 Safari 把開頭吃掉了，把游標移到最前面手動補打 javascript: 再存。
🤖 Android — 用 Firefox 編輯書籤
Chrome Android 不讓你建 javascript: 開頭的書籤，必須改用 Firefox（或 Kiwi Browser）。做法跟 iPhone 一樣：先存書籤、再把網址換成上面那段程式碼。
  1. 從 Play Store 安裝 Firefox，用它開啟本站
  2. 複製上方的書籤程式碼（同一段，iPhone / Android 通用）
  3. Firefox 右下「⋮」選單 → 點書籤圖示「加入書籤」存下這一頁
  4. 再開「⋮」→「書籤」→ 長按剛存的書籤 →「編輯」
  5. 名稱改「抓影音」；網址欄全選刪掉，貼上程式碼 → 儲存
  6. 之後在任何影片頁，開「⋮ → 書籤」點「抓影音」即可 ✅
💡 貼上後確認網址是 javascript: 開頭，被吃掉就手動補打。
